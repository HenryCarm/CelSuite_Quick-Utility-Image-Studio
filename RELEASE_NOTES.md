# CelSuite Quick Utility Image Studio — Release v269.30.0

The pixel kitchen: compress, convert, PNG&#8594;SVG, slice, auto-frame, sprite-resize — one tidy Qt app wrapped in a CelWeave-orange reactor UI.

---

## What's New in v269.30.0

- **First public release** of the Quick Utility Image Studio (QUIS).
- **Compress & Convert**: squeeze images to spec, bulk format swaps.
- **PNG &#8594; SVG**: clean vector traces out of pixel art.
- **Slice**: sprite sheets split into frames automatically.
- **Auto-frame & Sprite-resize**: borders and scaling that respect the grid.
- **Embedded Assets**: icon + orange CelWeave wallpaper baked into every build.
- **Nuitka Portable Builds**: one-file Windows `.exe` and Linux `.bin` — zero install.
